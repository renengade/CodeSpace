# CodeSpace
### Derrick的工作代码-清单
- datamerge.py    : 读取目标文件夹内，包含特定字符的文件，合并后输出结果。数据类型包括csv、xlsx、txt etc
- getcatologue.py : 读取目标文件夹内，所有的目录清单，可指定文件类型，folder、xlsx、png etc
- inspics.py      : 将目标文件夹内图片，按命名顺序插入到excel中，并展示插入位置及索引
- mwp_v2.py       : IT审计项目中，根据底稿模板自动生成指定项目的工作底稿
- repics.py       : 缩放文图片大小
- sampling.py     : 审计抽样程序


### 代码使用说明
在终端输入python xxx.py -h 查看具体的运行参数要求
